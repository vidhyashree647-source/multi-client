Socket Event Handlers Map

// Socket Event Registration Mapping
server.on('connection', (socket) => {
    logActivity(`Client ${socket.name} connected from ${socket.ip}`);
    broadcast('user_joined', socket.getMeta());
});

server.on('message', (packet) => {
    if (packet.target === 'ALL') {
        broadcast('chat_broadcast', packet);
    } else {
        unicast('private_chat', packet.target, packet);
    }
});

server.on('disconnect', (socket) => {
    broadcast('user_left', socket.name);
});

1. Socket Connection & Handshake

Clients establish a TCP full-duplex socket channel with the server using IP address and Port number. Once established, both parties can send messages at any time.

2. Message Broadcasting

When a client sends a message destined for ALL, the central server receives the payload packet and iterates through all active client socket descriptors to forward the message.

3. Unicasting (Private Messaging)

If a message target is specified (e.g. Rahul), the server bypasses general broadcast and delivers the message packet strictly to the recipient's socket handle.

4. Connection State Tracking

The server tracks active sockets, heartbeats, and disconnections to maintain an updated active client directory for all connected peers.
